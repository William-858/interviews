# 面試文件產生器

財團法人台灣水資源與農業研究院：新人面試用的 Word 文件產生網頁（純前端、免伺服器）。

## 使用方式

1. **面試官**：第一格填主面試官（主管）姓名，這一格必填。按「＋新增面試官」可以再加人，按「×」可以移除。
2. **選擇計畫**：可以複選，也可以按「全選」或「清除」。
3. **面試者**：填面試者姓名，按「＋」增加、「×」刪除。
4. **面試資訊（選填）**：面試日期、應徵職稱。留白的欄位不會印在文件上。
5. 按「產生並下載 ZIP」，下載的壓縮檔內容如下：
   - `面試官資料/面試官_{姓名}_{計畫}.docx`：每位面試官 × 每個計畫各一份，A4 不超過 4 頁，頁首印面試官姓名與面試小組名單
   - `面試者資料/面試者_{姓名}_{計畫}.docx`：每位面試者 × 每個計畫各一份，A4 不超過 2 頁

文件都在瀏覽器裡產生，資料不會上傳到任何伺服器。下載的 Word 檔可以直接編輯。

## 檔案結構

```
index.html        介面
js/data.js        13 個計畫的內容（面試者版＋面試官濃縮版）
js/docgen.js      Word 版面產生器
lib/docx.iife.js  docx 9.6.1（MIT）
lib/jszip.min.js  JSZip 3.10.1（MIT）
```

## 部署到 GitHub Pages

把整個資料夾推上 repo，再到 Settings → Pages 選擇 branch 就可以。

**注意**：公開的 repo 或 Pages 網址，任何人都能看到面試官資料（含題目與參考答案）。

## 更新內容

計畫內容在 `js/data.js` 的 `window.PROJECTS` 陣列裡，每個計畫的欄位如下：

- `candidate`：面試者版
- `interviewer_short`：面試官版

新增計畫時，照相同結構加一筆資料即可。
